# 🇷🇼 RWANDA SEARCH

### Discover More. Search Smarter. Explore Rwanda.

**RWANDA SEARCH** is a Windows desktop search application developed under the **VIATEUR HUB** brand. It provides a modern interface for discovering information through supported search categories, including Africa, Academic, News, and Technology.

## 🚀 Features

- 🔎 **Modern Search Interface** — A clean and user-friendly desktop experience.
- 🌍 **Africa Search** — Explore information related to Africa.
- 🎓 **Academic Search** — Find educational and academic resources.
- 📰 **News Search** — Explore news sources.
- 💻 **Technology Search** — Discover technology-related information.
- 📊 **Data Intelligence** — Access the data tools available in the application.
- 🪟 **Windows Desktop Application** — Designed for Windows computers.
- ✨ **Modern User Interface** — A polished interface designed for convenient navigation.

*Feature availability depends on the functionality included in the released version.*

## 📥 Download for Windows

**Latest version:** 1.0.0  
**Platform:** Windows 64-bit  
**Installer:** `RWANDA SEARCH Setup 1.0.0.exe`

### Installation

1. Open the [RWANDA SEARCH Releases](https://github.com/viateurirasubiza-dotcom/DATAVISION/releases) page.
2. Select the latest stable release.
3. Download `RWANDA SEARCH Setup 1.0.0.exe` from the release assets.
4. Open the downloaded installer.
5. Follow the installation wizard.
6. Launch RWANDA SEARCH from the Windows Start Menu.

**Important:** Download the installer only from the official project release page.
