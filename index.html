## 2. GitHub Pages & Release Deployment Guide
  1. Repository Setup: Create a public repository named rwanda-search-website under GitHub account viateurirasubiza-dotcom.
  2. Commit Code: Push index.html, README.md, and LICENSE to the main branch.
  3. Enable Pages: Navigate to Settings → Pages, select main branch root, and save. Website URL: https://viateurirasubiza-dotcom.github.io/rwanda-search-website/
  4. Release Publishing: Create software release tag v1.0.0 on the desktop app repository and attach installer asset named RWANDA SEARCH Setup 1.0.0.exe.
